# Contributing

Thanks for helping make AirCode better.

## Local setup

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm run check
npm run smoke
npm run build
```

## Project values

- Keep the app offline-first.
- Keep setup small and friendly.
- Do not commit proprietary problem statements.
- Prefer explicit, readable runner code over clever abstractions.
- Add runner types only when both Python and C++ behavior are clear.

## Problem content

Sample problems in this repository must be original or clearly licensed for redistribution. Users can import exact third-party problems into their own local browser storage, but those private imports do not belong in the public repo.
