# Security

AirCode executes local Python and C++ code. It is designed for trusted personal practice submissions on your own machine.

Do not expose the local server to a network or use it to run code from untrusted people. The development and production servers bind to `127.0.0.1` by default.

If you report a security issue, include:

- Operating system
- Node.js version
- AirCode version or commit
- Steps to reproduce
- Expected and actual behavior
